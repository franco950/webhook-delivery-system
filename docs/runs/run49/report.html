Once growth stopped (t+13 s for analytics, t+15 s for the fraud vendor), both cleared their backlog at 1,100–1,600 a second. The extra lanes do add capacity. The time spent getting them is what cost the deliveries.

Why each resize took most of a second

The barrier waits for the slowest party, and that's the logger

A resize can't start until every party has acknowledged. Lane workers answer within milliseconds, but endpointlogger checks resizecalled only after time.Sleep(1 * time.Second). So every resize waited until the logger's next tick, with the dispatcher and every lane worker paused.

The evidence: the endpoint snapshots, which the logger writes, show the lane count going up by exactly one step per tick. The gaps in attempts sit just before those ticks. In run 48 neither endpoint had a single gap over 0.2 s.

It also feeds itself. Each pause builds a backlog, and backlog makes checkpace add permits until tokencount reaches lanecount again, which starts the next resize. That's why analytics grew to 170 lanes when 750/s × 50 ms needs about 38. Run 48 carried it on 40.

Next

Make the pause milliseconds, then resize less often

  1. Don't let a sleeping goroutine hold the barrier

    The logger needs to notice a resize while it's waiting out its second, the same way an idle lane worker notices the closed wake channel. Alternatively, leave it out of the barrier, but then it mustn't read the lane map while it changes. The retry helper's 100 ms sleep has the same problem on a smaller scale.

  2. Grow in fewer, bigger steps

    +10 per resize meant 13–14 stops per endpoint. Doubling (40 → 80 → 160) would have taken 2. Also consider growing only when the backlog lasts, not the moment tokencount touches lanecount, because a pause by itself creates exactly that condition.

  3. Rerun this exact setup

    Same trace, same 1 ms sleep, same 40 starting lanes, with only the barrier fix. If pauses drop to milliseconds, analytics should refuse nothing, as in run 48. The fraud vendor should do better than run 48, because it gets the lanes it was missing.
